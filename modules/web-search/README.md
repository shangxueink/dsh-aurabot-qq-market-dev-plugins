# 网页搜索

启用控制台的浏览器服务，再启用本插件。聊天模型可以按关键词调用搜索工具，每次最多返回 8 条结果，包含标题、链接和页面提供的摘要。浏览器窗口会在请求结束后关闭。

| 配置项 | AI 工具标识 | 默认 |
| --- | --- | --- |
| 必应搜索 | `bing_search` | 开启 |
| B站搜索 | `bilibili_video_search` | 关闭 |
| 谷歌搜索 | `google_search` | 关闭 |

可以对机器人说「用必应搜索 FFmpeg 的官方文档，并给我链接」。三个开关分别决定模型可以调用哪些工具。站点需要人工验证或网络不可达时，工具会把失败原因返回给模型。
