# QQ 工具箱

为 QQ 实例提供平台专属工具。所有调用都从当前会话所在的 QQ Bot 发起，多账号时互不干扰。

- 协议扩展接口：`qq_api_find` 检索、`qq_api_call` 调用。非主人只能查询当前群的公开信息；主人调用也只能发往白名单里的人和群，外显文本先经过出站清洗。
- 群管：主人开口时禁言、解禁、全体禁言、踢人、改头衔、发公告。她会先确认自己在群里的身份。
- 资料：主人私聊里查看和发送当前头像；昵称、签名、头像的修改按插件设置分为关闭、仅主人、所有人三档。
- 申请：监听标准的 `friend-request`、`guild-member-request`、`guild-request` 事件，按账号保存待处理列表，可选私聊通知主人。被 QQ 过滤的好友申请也能列出和处理。

`GET /roles` 返回每个在线 QQ 实例在白名单群里的身份。
