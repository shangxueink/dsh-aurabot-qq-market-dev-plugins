# QQ 空间

使用支持空间扩展 API 的 QQ 适配器写日记、回复自己动态下的评论、浏览好友动态或点赞。定时任务和模型工具均依据所选 QQ Bot 操作。只有一个 QQ 实例时自动选取，同时使用多个实例时填写 botId。

日记的可见范围在插件设置中选择。部分好友可见、排除部分好友都需要明确填写 QQ 号。聊天中可以将一次发布收窄至仅自己可见。每日互动上限按评论数计算，点赞单独记录。每个 QQ 账号分别保存排期、互动记录和日记历史。

管理接口挂在插件自己的路径下。GET /state 查看账号状态、日记和近期互动。POST /diary/preview 生成预览，POST /diary/run 发布，POST /diary/sync 核对远端历史，POST /social/run 执行一次互动。
