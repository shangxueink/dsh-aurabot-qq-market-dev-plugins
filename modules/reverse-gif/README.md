# GIF 图片倒放

先在控制台的 FFmpeg 服务页确认可执行文件可用，再启用本插件。在群聊或私聊里发送 `倒放GIF`（也可按控制台配置使用 `/倒放GIF`）。机器人回复「请发送动图」后，一分钟内发送一张 GIF 图片。

插件通过 `ctx.ffmpeg` 读取动画的实际画面，按逆序保留每帧的停留时间、原始分辨率、透明度和循环设置。能直接重排的 GIF 复用原有帧数据，文件字节数相同。依赖前一帧的差分动画可能需要重新编码，输出大小会变化。发送前会核对解码后的每帧像素，无法无损还原时会提示原因。

回复使用 `image` 元素和表情标记。文件上限 16 MB，同时处理最多两张，单张最多 1000 帧、累计 3200 万画布像素。
