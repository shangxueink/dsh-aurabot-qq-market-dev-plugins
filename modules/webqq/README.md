# WebQQ

在 AuraBot V2 的「浏览 → WebQQ」打开 Stapxs QQ Lite 3.5.2。启用插件后，本机通过 5150 至 5159 之间的首个空闲端口提供静态前端。在 WebQQ 登录页填写你的 OneBot 服务地址及对应凭据。浏览器按地址保存客户端设置。

构建时从[上游 v3.5.2 发行页](https://github.com/Stapxs/Stapxs-QQ-Lite-2.0/releases/tag/v3.5.2)获取 web.zip，并校验 SHA-256。离线构建可将 WEBQQ_ARCHIVE 指向同一份 ZIP。安装后的静态文件随插件提供。前端作者为 Stapxs 和上游贡献者，[对应源代码](https://github.com/Stapxs/Stapxs-QQ-Lite-2.0/tree/v3.5.2)采用 AGPL-3.0 许可。
