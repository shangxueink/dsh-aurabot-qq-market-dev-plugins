# 哔哩哔哩

安装后可在任何平台的会话中让模型查看视频、分 P、字幕和热评，或按关键词搜索。匿名浏览可先留空账号字段。需要登录时，在哔哩哔哩官方页面登录后手动填写账号凭据。插件以只读方式浏览站内内容。

自动浏览按话题和浏览记录挑选视频，保存观后感并写入已安装的记忆服务。可选择安装 FFmpeg 以截取视频画面。开启「允许日记等插件读取」后，QQ 空间可以选用自主浏览过的视频或画面。

主动分享需要设置平台、Bot 实例、会话类型和目标 ID。私聊目标须为该平台与实例的主人。群和频道分享进入待批队列，可在主人的私聊中回复「分享 编号」或「跳过 编号」。工具产生的视频帧回复会发回当前会话。

在仓库根目录执行 `npm run dry-run` 可构建本地安装包。
